What does log signifies?
  – log ka mtlb h logger
  --In console.log(), the word log is a programming method that represents a chronological record of events or data, 
  -Technically, log is a method (a built-in function) belonging to the global console object provided by the browser or Node.js environment. 
  -Developers use console.log() primarily for visibility. Because JavaScript runs silently behind the scenes inside the browser, you cannot naturally "see" what the code is doing. console.log() acts as an X-ray machine 
  -Historically, developers used alert() to see what their code was doing. console.log() was introduced to solve all of alert()'s massive flaws, making it absolutely necessary for modern programming
